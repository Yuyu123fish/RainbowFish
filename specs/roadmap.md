# RainbowFish 功能开发路线

状态：功能顺序已确认，各阶段尚未实施。更新日期：2026-10-04。

这份文档记录先做哪些功能，以及每个阶段做到什么程度。具体需求、接口和验收条件在对应 Feature 中细化，开发步骤遵循 [WORKFLOW.md](WORKFLOW.md)。阶段编号表示功能顺序，不直接对应 Feature 编号；一个阶段可以按实际范围拆成多个 Feature。

## 功能顺序

基础对话与项目管理 → 文本记忆 → 接入一个外部 Agent → 项目会话关联与发现 → 完善自身任务执行 → 多模态资料与记忆 → 可视化工作流。

先让用户能够在虹忆中讨论项目、积累和复用记忆，再验证其他 Agent 能否使用这些记忆并接续相关会话。后续围绕实际任务扩展执行能力、资料类型和工作流。

## 1. 基础对话与项目管理

提供虹忆自己的日常使用入口。

- 创建项目，在项目中发起会话。
- 调用模型进行对话，保存历史消息。
- 重新打开项目和历史会话，继续讨论。

完成标志：用户可以在虹忆中讨论一个项目，退出后再次打开，能够找到原来的会话并继续对话。

这一阶段先提供基础对话。工具和 Skill 可在实际需要时逐步加入，任务执行能力在第 5 阶段集中完善。

## 2. 文本记忆

让不同会话能够复用已经积累的信息，这是项目最早需要验证的核心能力。

- 从对话或文字资料中保存有复用价值的记忆。
- 区分个人记忆与项目记忆，按相关范围检索和使用。
- 查看记忆及其来源，支持修改和纠正，能够辨认当前结论与旧记录。
- 保留用户明确表达、材料记载和模型推断的区别。

完成标志：在一个会话中保存项目决定，新开会话后仍能找回并查看来源；纠正决定后，后续读取能识别更新后的结论。

自动提取的时机、是否需要确认、冲突处理和具体检索方式，在本阶段的 Feature 中确定。

## 3. 接入一个外部 Agent

让外部 Agent 使用虹忆已经建立的同一套记忆。

- 从 Codex、Claude Code、pi 中选择一个作为首个接入宿主，具体选择尚未确定。
- 支持在允许的范围内读取和写入个人或项目记忆。
- 将虹忆中的决定用于外部 Agent 的任务，并将有价值的任务结论保存回来。

完成标志：虹忆中保存的一项项目决定可以被外部 Agent 找到并使用；外部 Agent 保存的新结论，也能在虹忆中查看和追溯。

具体接入方式和读写时机按选定宿主的实际能力确定。后续宿主复用已验证的能力逐步接入，不在这一阶段同时完成所有宿主适配。

## 4. 项目会话关联与发现

在共享记忆之外，进一步帮助用户和 Agent 找到产生信息的具体讨论。

- 将外部 Agent 的具体会话关联到虹忆项目。
- 展示和查询相关会话的列表、摘要与来源。
- 支持按需读取相关讨论，帮助新的会话接续上下文。

完成标志：另一个会话能够发现同一项目中此前的相关讨论，并在允许读取的范围内取得摘要和必要的原始记录。

这一阶段承诺的是会话关联、发现和读取。主动向外部会话投递消息、等待回复、唤醒 Agent，以及刷新正在运行的会话上下文，仍属于待讨论能力。

## 5. 完善虹忆自身的任务执行

让用户直接在虹忆中完成更多实际任务。

- 按任务需要接入工具和 Skill，用它们组织具体业务方法。
- 支持查看执行过程、结果和产物。
- 将有价值的执行结果沉淀为记忆，继续使用前面建立的来源与纠正能力。

完成标志：用户可以在虹忆中完成一项明确的工具任务，查看过程和结果，并在后续会话中复用留下的记忆。

核心保持精简。第 5 阶段用于集中完善任务执行体验，前面阶段有实际需要时即可接入相应工具和 Skill。

## 6. 多模态资料与记忆

在文本记忆的基础上扩展资料类型，顺序为图片、音频、视频。

- 先支持图片的理解、检索和原图回读。
- 再支持音频、视频中的内容进入记忆，并能定位对应片段。
- 保留原始材料与记忆的关联，使用摘要检索后仍能回到依据。

完成标志：用户能够从某份多模态资料中找回相关信息，并打开对应原图或音视频片段核对。

每种模态分别明确范围和验收条件，具体处理方式在相应 Feature 中确定。

## 7. 可视化工作流

把已经可用、值得重复执行的操作组织为工作流。

- 将模型、工具、Skill 和记忆操作按实际需要组织为节点。
- 支持拖拽、连线、保存和执行工作流。
- 支持查看节点执行结果。

完成标志：用户能够把一个已经验证可用的处理过程保存为工作流，再次运行并查看各步骤的结果。

节点类型、输入输出、执行规则及暂停和恢复方式在本阶段设计。React Flow 承担节点编辑界面，执行能力需要单独实现。

## 分段使用目标

- 第 1、2 阶段完成后，形成首个可用版本：在虹忆中讨论项目，保存决定，换会话后能够找回、核对和纠正。
- 第 3、4 阶段完成后，验证跨 Agent 接续：外部 Agent 复用共享记忆，并能发现和读取相关会话。
- 第 5 至 7 阶段逐步扩展可完成的任务、可处理的资料和可复用的工作流，每个阶段单独验收。

当前确定的是上述功能顺序。首个宿主、模型、自动采集策略、详细交互和具体实施拆分仍需在对应 Feature 中确定。本路线不设定日期和工期；工程初始化等支撑工作随功能安排，具体技术基线见[技术栈](../docs/technical-stack.md)。
